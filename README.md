# TP17 - Architecture Android Multi-Module

Ce projet illustre la mise en place d'une architecture Android Multi-Module structurée avec **Kotlin DSL**.

## 🏗️ Structure du Projet

* **`:app`** : Module d'interface utilisateur (UI, ViewModels, Activities).
* **`:data`** : Module de gestion des données (Repositories, Data Sources, API/Database).
* **`:domain`** : Module contenant la logique métier (Business Logic, Use Cases, Models).

## 🛠️ Technologies Utilisées
* **Langage :** Kotlin
* **Build System :** Gradle (Kotlin DSL `.gradle.kts`)
* **Architecture :** Clean Architecture Multi-Module
